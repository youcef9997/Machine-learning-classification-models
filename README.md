## 🧠 Project Overvie

This project explores the development of a machine learning classification model using an Artificial Neural Network (ANN). The notebook covers the complete machine learning workflow, from data preprocessing and exploratory data analysis through to feature preparation, model training, evaluation, and performance analysis.

The aim is to demonstrate the practical application of machine learning techniques using Python and industry-standard libraries, while providing a clear and reproducible workflow from raw data to a trained and evaluated model.

## 🤖 Machine Learning Approach

- Data preprocessing
- Exploratory data analysis
- Feature engineering
- Artificial Neural Network (ANN)
- Model training
- Model evaluation
- Performance analysis

## 📊 Results

The developed Artificial Neural Network (ANN) was trained and evaluated on the pneumonia classification dataset. The project follows a structured machine learning workflow, using stratified data splitting to maintain class distribution between the training and testing datasets.

Model performance was evaluated using classification metrics and validation results to assess how effectively the ANN generalised to unseen data. The notebook contains the complete evaluation process, including the model’s predictions and performance analysis.

Full results, evaluation metrics, and visualisations are available in the Jupyter Notebook.
